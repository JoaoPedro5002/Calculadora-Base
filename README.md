# Calculadora Interativa em Python (CLI)

Um sistema de calculadora simples, interativo e robusto desenvolvido em **Python** para execução direto pelo terminal (CLI). O programa permite realizar operações matemáticas básicas, conta com proteção contra divisão por zero e oferece um fluxo contínuo com opção de encerramento controlado pelo usuário.

---

## 🚀 Funcionalidades

- **[1] Soma:** Realiza a adição entre dois valores informados.
- **[2] Subtração:** Calcula a diferença entre o primeiro e o segundo valor.
- **[3] Multiplicação:** Efetua o produto entre os dois números.
- **[4] Divisão:** Divide o primeiro valor pelo segundo, com validação inteligente para evitar erros de divisão por zero.
- **Controle de Fluxo:** Ao final de cada operação, o sistema pergunta se você deseja continuar (`S/N`), validando a resposta para garantir uma experiência fluida.

---

## 🛠️ Tecnologias Utilizadas

- **Python 3.x** (Desenvolvido inteiramente com recursos nativos, sem necessidade de instalação de dependências externas).

---

1. Certifique-se de ter o **Python 3** instalado em sua máquina.
2. Baixe ou clone este repositório contendo o script da calculadora.
